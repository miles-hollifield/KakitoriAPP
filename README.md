# Kakitori

Kakitori is a Japanese language learning web app built with React, Vite, and MaterialUI.

## Project Structure

```
src/
├── assets/       # Images, logos, icons, etc.
├── components/   # Reusable components (Navbar, Sidebar, etc.)
├── pages/        # Main app pages
├── features/     # Core feature modules (Kanji, Vocab, etc.)
├── hooks/        # Custom React hooks
├── utils/        # Utility functions
├── services/     # API calls and backend services
├── contexts/     # Context API providers (auth, theme, user)
├── styles/       # Global styles, MUI theme config
└── App.jsx       # Root component
```

## Tech Stack
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Material UI](https://mui.com/)

## Getting Started
1. Install dependencies:
   ```powershell
   npm install
   ```
2. Start the development server:
   ```powershell
   npm run dev
   ```

This project is scaffolded with Vite and ready for frontend development. Backend setup will be added later.
